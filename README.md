# Coordination

手持ちの服のデータをもとに、**日付（季節）・気温・色味** を考慮したコーディネートを提案する Web アプリです。
サーバー不要で、データはブラウザの localStorage に保存されます。

## できること

- **クローゼット管理**: 服をカテゴリ・ブランド・色（主色 / 副色）・着る季節・厚さ・テイスト・タグ付きで登録、編集、削除
- **コーデ提案**: 日付（省略時は今日）と任意の気温・テイスト・「このアイテムを着たい」指定から、上位 5 コーデを提案
- **気温の自動取得**: 日付を選ぶと東京の天気予報（Open-Meteo、API キー不要）から最高気温を取得して気温欄に反映。結果は 6 時間キャッシュ。手入力で上書き可
- **コーデのイラスト表示**: 提案ごとに、登録した色で塗り分けた人型シルエットを SVG で描画（半袖 / 長袖、アウターの丈、副色のアクセントを反映）
- **ブランド登録**: アイテムにブランド名を任意で登録。カードに表示し、検索欄で絞り込み可。登録済みブランドは入力候補に表示
- **提案の根拠を表示**: 配色の種類（モノトーン / ベーシック＋差し色 / 類似色 など）、厚さの適合、テイストの統一、季節外れの警告
- **JSON のエクスポート / インポート**: バックアップや別ブラウザへの移行に
- **サンプルデータ**: 空の状態からすぐに試せる 30 点のサンプルクローゼット

## 使い方

Node.js 24 系が必要です。[mise](https://mise.jdx.dev/) を使っていれば `mise.toml` の設定で自動的に選ばれます。

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm test           # ロジックのユニットテスト (vitest)
npm run build      # 型チェック + 本番ビルド (dist/)
npm run preview    # ビルド結果をローカルで確認
```

静的サイトとしてビルドされるので、Vercel / Netlify / GitHub Pages などにそのまま配置できます。

## 提案ロジックの概要

スコアは 4 つの観点の加重和です（`src/lib/outfit.ts`）。

| 観点 | 重み | 内容 |
| --- | --- | --- |
| 色 | 45% | 全アイテムの色をペアごとに評価。ベーシックカラー（白・黒・グレー・ネイビー・ベージュ・ブラウン・カーキ）はどの色とも相性が良いとみなし、有彩色同士は色相差で「同系色 / 類似色 / 補色 / 相性が悪い」を判定。差し色が 3 系統以上あると減点 |
| 厚さ | 30% | 気温（または季節と月内の進行）から目標の厚さ 1〜5 を決め、コーデ全体の体感的な厚さ（アウターを重視）との差で評価。寒い日にアウターが無いと減点 |
| テイスト | 15% | カジュアル / きれいめ / フォーマルの統一度。指定があればそれへの近さも考慮 |
| 季節 | 10% | 各アイテムの着用季節が今日の季節に合っているか。季節の境目（最初と最後の約 3 週間）は隣の季節の服も許容 |

季節は日本の一般的な区分（3〜5 月 春、6〜8 月 夏、9〜11 月 秋、12〜2 月 冬）です。
色の判定ロジックは `src/lib/color.ts`、季節と気温の変換は `src/lib/season.ts` にあります。

## 構成

```
src/
  App.tsx                 タブ切替と永続化
  types.ts                データ型と表示ラベル
  lib/color.ts            色の解析・分類・相性スコア
  lib/season.ts           日付 → 季節、気温 → 目標の厚さ
  lib/weather.ts          東京の天気予報の取得とキャッシュ
  lib/outfit.ts           コーデ生成とスコアリング
  lib/figure.ts           コーデ → イラストの描画パーツ
  lib/brand.ts            ブランド名の正規化と候補一覧
  lib/storage.ts          localStorage と JSON 入出力
  data/sample.ts          サンプルクローゼット
  components/             画面コンポーネント
    OutfitFigure.tsx      人型シルエットの SVG 描画
```

## 今後の拡張候補

- 天気予報の地点選択、最低気温を使った朝晩の冷え込み警告
- Supabase などへの同期で複数デバイス対応

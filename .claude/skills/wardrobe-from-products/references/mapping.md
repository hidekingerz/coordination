# 属性の判定ルール

商品ページの情報 → アプリの 5 属性への対応表。例外はいくらでもあるので、
「このアプリはこの属性をどう使うか」を踏まえて最終判断する:

- `category` は組み合わせの骨格 (トップス+ボトムス or ワンピース、+靴、+アウター、+小物)
- `warmth` と `seasons` はその日の気温・季節での候補絞り込み
- `color` は配色スコア (全体の 45%)
- `formality` はテイストの統一度

## category

| アイテム語 (日本語 / 英語 / FR の breadcrumbs) | category |
| --- | --- |
| T シャツ, カットソー, ロンT, ポロ, シャツ, ブラウス, ニット, セーター, カーディガン (インナー寄りの薄手), スウェット, パーカ, フリース (薄手), タンクトップ / `tops`, `sweatshirts`, `knitwear`, `shirts` | `tops` |
| コート, ジャケット, ブルゾン, ダウン, パッファー, マウンテンパーカ, トレンチ, チェスター, ステンカラー, ボア, 厚手フリース, 羽織り用カーディガン, ベスト (アウター用途) / `outerwear`, `jackets and coats` | `outer` |
| パンツ, デニム, ジーンズ, チノ, スラックス, ワイド, テーパード, カーゴ, ショーツ, ハーフパンツ, スカート, レギンス (外着) / `pants`, `bottoms`, `jeans`, `skirts`, `shorts` | `bottoms` |
| ワンピース, ドレス, オールインワン, サロペット, セットアップ, スーツ上下 / `dresses`, `jumpsuits`, `set up` | `onepiece` |
| スニーカー, ブーツ, ローファー, 革靴, サンダル, パンプス, スリッポン / `shoes`, `footwear` | `shoes` |
| バッグ, リュック, 帽子, キャップ, ニット帽, マフラー, ストール, 手袋, ベルト, ソックス, アクセサリー, サングラス / `accessories`, `bags`, `hats` | `accessory` |

迷う例:
- カーディガン: 薄手で中に着るなら `tops`、ざっくり厚手で羽織るなら `outer`。アプリは `outer` を「寒い日に必須寄り」として扱うので、春秋に 1 枚で羽織る用途なら `outer` で warmth 2〜3 がよい。
- ベスト / ジレ: 羽織るなら `outer` (warmth は低め)。
- セットアップ上下を別々にも着る人は、上下を `tops`+`bottoms` で 2 件に分ける方が提案の幅が出る。

## warmth (1〜5) — 素材と機能名から

| 手がかり | warmth |
| --- | --- |
| リネン, 麻, エアリズム, ドライ, メッシュ, 薄手綿 T シャツ, ショーツ, サンダル | 1 |
| 綿ブロード / オックスシャツ, 薄手ロンT, 薄手カットソー, レーヨン / ポリエステルの軽いパンツ, キャンバススニーカー | 2 |
| スウェット, 裏毛, デニム, チノ, ウールライクのスラックス, 中厚ニット (コットン), 薄手カーディガン, 薄手ブルゾン / トレンチ, レザースニーカー, ローファー | 3 |
| ウール / メリノニット, ラムウール, フリース (中厚), コーデュロイ, 裏起毛, ウールパンツ, ステンカラー / チェスターコート (中綿なし), ブーツ, ヒートテック (通常) | 4 |
| ダウン, 中綿 (パッファー), ウールメルトンコート, 厚手ボア, ヒートテック極暖 / 超極暖, 厚手タートル, マフラー / 手袋 | 5 |

- アウターは「その 1 枚の厚さ」。アプリはアウターを体感の 7 割として計算する。
- 混率は本体の主素材で見る (「本体: 100% 綿」など)。リブやフード裏は無視。
- 「ヘビーウェイト」「厚手」とあれば +1、「ライトウェイト」「薄手」「シアー」とあれば -1。

## seasons — warmth から

| warmth | seasons の既定 |
| --- | --- |
| 1 | `summer` (+ 春・秋も着る T シャツなら `spring, summer, autumn`) |
| 2 | `spring, summer, autumn` |
| 3 | `spring, autumn` (+ 冬にインナーで着るなら `winter` も) |
| 4 | `autumn, winter` (+ 3 月に着るコートなら `spring` も) |
| 5 | `winter` |

通年もの: デニム, 黒スラックス, レザースニーカー, ローファー, ベルト, バッグ → 4 季節すべて。
アプリは季節の境目 (各季節の最初と最後の約 3 週間) で隣の季節の服も候補にするので、境界を厳密に悩まなくてよい。

## formality — アイテム種別から

| casual | smart | formal |
| --- | --- | --- |
| T シャツ, スウェット, パーカ, デニム, カーゴ, ショーツ, スニーカー, キャップ, マウンテンパーカ, ダウン, フリース | シャツ, ブラウス, ニット, カーディガン, スラックス, テーパード / ワイドパンツ (きれいめ素材), チノ (細身), ローファー, 革靴 (カジュアル寄り), トレンチ, ステンカラー, チェスター, ジャケット (テーラード) | スーツ, セットアップ (ウール), ドレスシャツ, ドレスシューズ, フォーマルワンピース |

- 名前に「感動」「スマート」「ドレープ」「タック」「センタープレス」「ウールライク」が付くボトムスは `smart`。
- 同じ「パンツ」でも「イージー」「スウェット」「カーゴ」「ジョガー」は `casual`。
- 迷ったら `smart` より `casual` に倒す方が提案で浮きにくい (ユーザーは後から直せる)。

## color — 色名 → hex

ブランドの色名は装飾が多い。まずベーシック 7 色 (白・黒・グレー・ネイビー・ベージュ・ブラウン・カーキ) に該当するか判断し、

## tags の付け方

2〜5 個。優先順: アイテム種別 (パーカ) > 主素材 (綿100%, ウール) > 機能・シリーズ名 (ヒートテック, エアリズム, 感動パンツ) > シルエット (ワイド, オーバーサイズ) > 用途 (通勤, 部屋着)。
ブランド名はタグに入れない (`brand` にある)。色も入れない (`color` にある)。
